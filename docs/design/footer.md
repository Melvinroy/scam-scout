# Footer

Captured 21 Oct 2026. Last block on the home page. A short closing band sits above it. UI repos were read as style references only. Nothing from them was copied.

## What we looked at

- [Nebius](https://nebius.com). The footer repeats the groups from the top bar, then a logo and a legal line. The map is the contract. It is not a second hero.
- [RibbonPay](https://ribbonpay.example/). Columns for products, solutions, developers, and company. The legal line is a separate quiet row. The selling action lives above the map, in the page, not inside the link columns.
- [Linecraft](https://linecraft.example/). Short columns. The type stays the product’s type. Nothing in the footer shouts.
- [Vercel](https://vercel.com/). Logo, a dense scannable map, a legal line. No second product demo.
- [DesignLaurels, creative footers](https://www.designlaurels.example/15-excellent-creative-website-footers.html) and the [footer collection](https://www.designlaurels.example/websites/footer-design/). The footer is the way into the architecture of the site. Type stays legible. A creative close still has to be a map, not a poster.
- Nielsen Norman Group’s footer patterns, and the 2026 column guides that cite RibbonPay, Linecraft, and Vercel. Four to six columns. One action above the map. On a short site, stack the columns on a phone rather than hiding them. No newsletter here, because this project does not send one.

## Chosen pattern

Two pieces.

The closing band is one line and one action. “Before you pay.” Check now returns to the field at the top. Sign in is the path to a live check. It is not a second form and not a second case file.

The footer is the site map. The badge and one mission line sit first. Under that, five columns in the same order as the menus: Product, Use cases, Trust & Safety, Playground, Developers. Each column is a colour rule and a list of the same pages. No boxes, no icons, no table.

The base line, and only the base line, names vendors: Tavily, NVIDIA Nemotron, Nebius Token Factory. Beside it: “Built by Melvin Roy, independent builder.” The advisory sentence. “A hackathon build.” The year and the MIT licence.
