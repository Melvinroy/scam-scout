# Playground

`/world` had been restyled as a plain light page with the old night desk dropped underneath. It looked copied because the only designed surface was the game, and the page around it had no relationship to the product.

## References

- [Nebius](https://nebius.com). A dark product exhibit is framed by the light site. The exhibit is not the whole page.
- [Bruno Simon](https://bruno-simon.com). The reason the game exists: a world you step into, with the chrome kept out of the way once you are in it. We do not restyle the town.
- [Vercel](https://vercel.com/ship) and other product-festival pages. A side experience gets its own intro, then the experience, then a way back to the product.
- [Linecraft](https://linecraft.example). Playful product moments still use the same wordmark and colour.

## This page

`/playground` introduces the two rooms as large cards. `/world` opens with the same badge, type and washes, then frames the existing town in a plum rim with a colour mesh. The game block stays on the night desk, including its type and gold, because that is the game. `/spot` gets the same light intro, then the night stage. Neither page is linked from the hero.
